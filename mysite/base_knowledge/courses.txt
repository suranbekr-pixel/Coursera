Образовательная платформа Coursera (Курсы и программы обучения)

1. Курс: Основы программирования на Python (Python Basics)
Категория: Программирование и разработка
Уровень: beginner (начинающий)
Длительность: 4 недели (duration_weeks: 4)
Стоимость: Бесплатно (status: free, price: 0 сом)
Описание: Идеальный базовый курс для начинающих программистов. Изучение базового синтаксиса Python, переменных, циклов, функций, работы со списками и словарями. Продолжительность ровно 4 недели.

2. Курс: Быстрый старт в Python и автоматизация
Категория: Программирование и разработка
Уровень: beginner (начинающий)
Длительность: 3 недели (duration_weeks: 3)
Стоимость: 8 000 сом (status: plus, price: 8000)
Описание: Интенсивный курс по автоматизации рутинных задач с помощью Python scripts, работа с файлами, Excel и парсинг сайтов. Длительность до 4 недель (3 недели).

3. Курс: Python Backend Разработчик (Django & FastAPI)
Категория: Backend разработка
Уровень: intermediate (средний)
Длительность: 12 недель (3 месяца)
Стоимость: 35 000 сом (status: plus, price: 35000)
Описание: Профессиональный курс по созданию веб-сервисов и API на FastAPI, реляционным базам данных PostgreSQL/SQLite, SQLAlchemy, Alembic, Docker и авторизации с JWT токенами.

4. Курс: Data Science и Машинное обучение на Python
Категория: Искусственный Интеллект и Data Science
Уровень: intermediate (средний)
Длительность: 8 недель (2 месяца)
Стоимость: 25 000 сом (status: plus, price: 25000)
Описание: Анализ данных с Pandas, NumPy, визуализация с Matplotlib/Seaborn, введение в алгоритмы машинного обучения с Scikit-Learn и основы нейросетей.

5. Курс: Frontend разработка: Современный React & TypeScript
Категория: Веб-разработка
Уровень: beginner (начинающий)
Длительность: 10 недель
Стоимость: 30 000 сом (status: plus, price: 30000)
Описание: Современная верстка, основы JavaScript ES6+, разработка интерфейсов на React, управление состоянием с Redux Toolkit и интеграция с бэкендом.

6. Курс: Введение в базы данных и SQL
Категория: Базы данных
Уровень: beginner (начинающий)
Длительность: 4 недели (duration_weeks: 4)
Стоимость: Бесплатно (status: free, price: 0 сом)
Описание: Основы реляционных баз данных, написание запросов SELECT, INSERT, UPDATE, JOIN, индексация и проектирование таблиц.
